# Moshtare LP Releases

This repository contains verified Windows installer release assets for Moshtare LP.

## Release status

- Releases marked **Pre-release** are pilot builds. Public availability does not mean production acceptance.
- Verify the installer with the accompanying `.sha256` file before running it.
- Production signing and broad Windows distribution qualification remain separate release gates.

## Security and support

This repository intentionally contains no application source, private receipt samples, credentials, signing keys, internal manifests, or audit material. Use the official Moshtare LP website for installation links and support.
